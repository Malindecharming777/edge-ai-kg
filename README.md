## 📖 What Is This?

edge-ai-kg is a **visual knowledge graph** that shows you how edge AI models can be deployed on different hardware. Think of it as a smart map that connects:

- **Boards** – small computers like Raspberry Pi or NVIDIA Jetson
- **Accelerators** – chips that make AI calculations faster
- **ONNX operators** – building blocks for AI models
- **Quantized models** – compressed AI models that run faster

This tool uses **real data** from popular AI frameworks and combines it with realistic examples to give you a complete picture. It runs on the **Samyama Graph** engine, which handles complex relationships smoothly.

## 🆘 Troubleshooting

### The Window Appears Blank

- Wait 10 seconds for initial loading
- Make sure your graphics driver is updated
- Restart the application

### Search Returns No Results

- Check your spelling
- Try broader terms like "model" instead of "MobileNet"
- Clear filters if any are active

### Application Crashes Immediately

- Ensure you have at least 2 GB free RAM
- Close other heavy programs temporarily
- Verify Windows is up to date

### Graph Shows Too Many Connections

- Use the "Expand" slider to reduce node connections
- Apply more specific filters
- Zoom in closer to focus on one section

## 🤔 Frequently Asked Questions

**Q: Is this a database I need to set up?**  
A: No. Everything is pre-packaged – just open and view.

**Q: Can I export or print the graph?**  
A: Yes, look for the export button in the top-right corner. You can save images or PDF files.

**Q: Does this work offline?**  
A: Absolutely. All data is stored locally on your computer.

**Q: Can I add my own data?**  
A: The current version is read-only for simplicity. A "contribute" mode is planned for future releases.

**Q: What is ONNX exactly?**  
A: ONNX (Open Neural Network Exchange) is a standard format for AI models, like MP3 for music or JPEG for images.

**Q: What is quantization?**  
A: Quantization compresses AI models so they run faster on small devices, like reducing a 4K photo to save space while keeping it clear enough.
